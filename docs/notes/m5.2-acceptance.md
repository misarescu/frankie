## Found and fixed during acceptance

- **D82:** a retried run failed with "agent session made no changes" when its coder found the earlier run's commit already doing the job. That was gc-34's second run; its first had failed when cluster DNS could not resolve `api.github.com` during a short internet outage. Now:
  - a retried run takes over the branch's earlier work;
  - the GitHub client retries requests that never reached GitHub for about 45 s.

  On gc-33's last run, the coder kept the branch's commit and the run went on to review and the gate.
- **D83:** gc-33's coder gave its final answer but left a background shell loop waiting for a line that never came. Claude Code does not exit while such a task runs, so the session sat silent until the 20-minute idle timeout failed it. The adapter now stops claude 2 minutes after it goes silent with every message answered, and keeps its result. This happened again on the next run of gc-33, which then succeeded.
- **`go-packages.txt`:** it is now generated for linux/amd64 on every machine. A dependency imported `klauspost/compress/internal/cpuinfo` only on amd64, so the list differed between a Mac and CI.

## Findings for later

- **Egress bootstrap:** a project cannot use Frankie to add an egress host that its own toolchain rebuild needs. A run reads the list from the base branch, so the run that would add the host fails at the build first. Goodreads-Clone's `nodejs.org` went in by hand (#67, with the commit gc-34 had pushed). A per-run egress override for people, or the deployment list as a temporary fallback, would close the loop.
- **Coder memory:** coders peaked at 2.59 GiB of their 3 GiB limit (M5.1: 2.6 GiB). The profile's budget has 1.6 GiB of headroom, so 3.5 GiB would fit if it keeps creeping up.
- **Registry storage:** the registry holds 10.4 GiB of blobs on a 10 Gi `local-path` volume, which does not enforce its size (the host disk has 784 GB free). Nothing is ever deleted, and every runner tag adds:
  - a mirrored base image of about 1 GB;
  - about 0.6 GB of toolchain image and 0.7 GB of dependency image per project.

  The #92 experiment images (`experiments/`) can go. Registry garbage collection of unrecorded digests is open.
- **Build Job TTL:** build Jobs disappear 10 minutes after they finish (D78), so timings have to come from the control plane log ("image ready") once they are gone.
