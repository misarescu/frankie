# M7.1 sizing run (2026-11-19)

What does one issue cost the factory? M7.1 puts a complete factory in each Frankie change request's preview (D131), so this run measured the production factory on Kapsule while it built one small project, the one the previews will build (D132).

## The run

`misarescu/frankie-dummy` was added to the factory as project `dum` (frankie#157, deployed by frankie-cd#32 as `sha-6bb0a0b`). Its seed holds only a Go toolchain, the factory's config, an acceptance suite and the spec of a todo service with CRUD endpoints. Issue `dum-1` ("Build the todo service") ran `default-build` with the platform default model (Claude Code, Sonnet) and merged in one pass, as change request frankie-dummy#2. `main` was then reset to `seed`, and the result kept as tag `sizing/dum-1`.

| Phase (UTC) | Time | |
|---|---|---|
| 16:37 to 16:43 | 6 min | An agent node started: the pool was at zero |
| 16:43 to 16:46 | 3 min | The dummy's toolchain image was built |
| 16:46 to 16:48 | 1m45s | `implement` ($0.105) |
| 16:48 to 16:50 | 2 min | `checks`: `mise run lint` and `mise run test`, the acceptance suite included |
| 16:50 | 14 s | `code-reviewer` ($0.023) |
| 16:50 to 16:53 | 2m20s | Merge queue: update, gates again, the repo's CI (none) and the merge |

16 minutes and $0.128 in all, more than half of it starting a node and building the image.

## For a preview

- The platform without the web UI peaked at about 0.2 CPU and 1.1 GiB, LiteLLM 0.7 GiB of it. Its requests are about 0.4 CPU and 1 GiB.
- Agent pods reserve far more than this project uses: a 2Gi limit leaves the coder three times its peak.
- One step running in a preview then requests about 5 GiB with Kata's overhead (1Gi on Kapsule, D106) and the guest headroom (512Mi, D103), so two previews fit a POP2-4C-16G.
- A cold agent node and a toolchain build add about 9 minutes, which the preview's readiness timeout has to cover (D131 (5)).

This was one small issue on a quiet factory, so it says nothing about the production control plane under ten issues at once; it does size a preview, which runs one.
